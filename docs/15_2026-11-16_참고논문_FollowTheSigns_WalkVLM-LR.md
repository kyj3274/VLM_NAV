# 15. 참고 논문 2편 정리 (우리 구조에 쓸 것)

2026-11-16 · 본문(arXiv HTML)을 읽고 정리. 숫자는 논문이 스스로 밝힌 값.

## 1. Follow the Signs (arXiv 2601.06652, 2026.1)

Cao, Kumar, Curtis. "Follow the Signs: Using Textual Cues and LLMs to Guide Efficient Robot Navigation". https://arxiv.org/abs/2601.06652

**하는 일**: "621호로 가" 같은 번호 목적지를, 보기 전에 호실 번호 규칙과 표지판으로 위치를 추정해 찾아간다.

**구조**
1. LLM이 명령에서 목적지 번호를 뽑는다 ("621").
2. 지금까지 본 것을 격자 두 장에 쌓는다: 어디를 봤나(점유), 어디에 어떤 글자가 있었나(의미).
3. 목적지가 아직 안 보이면 LLM에 두 격자와 현재 위치를 주고 묻는다. LLM은 세 가지를 답한다.
   - 추론 설명
   - 찾은 규칙 (예: "번호가 오른쪽으로 커진다", "홀수와 짝수가 복도 양쪽으로 나뉜다")
   - 목적지가 있을 것 같은 방향
4. **확신 격자**: 매 단계 전체를 조금씩 줄이고(α배), LLM이 말한 방향 칸을 +1 한다. 가 봤는데 목적지가 아닌 칸은 0으로.
5. 확신이 가장 높은 곳을 하위 목표로 A*로 간다. 확신이 없으면 가장 가까운 미탐색 지역으로 간다(프론티어 탐색).
6. 목적지가 보이면 바로 그리로.

**결과 (경로 효율 SPL / 성공률, 표 1)**

| | 작은 맵 | 큰 맵(실제 평면도) | 3D 스캔(노이즈) |
|---|---|---|---|
| 이 방법 | 0.83 / 0.97 | 0.74 / 0.97 | 0.66 / 0.80 |
| 프론티어 탐색만 | 0.68 / 1.00 | 0.65 / 1.00 | 0.46 / 1.00 |
| NavGPT | 0.28 / 0.80 | 0.19 / 0.33 | 0.15 / 0.20 |
| LLM 단독 | 0.32 / 0.60 | 0.05 / 0.17 | 0.03 / 0.20 |

- LLM 단독은 이웃 칸을 왔다 갔다 하거나 불가능한 이동을 고른다. NavGPT는 기록 요약에서 번호 규칙을 놓친다.
- 실패: 600A·617A처럼 규칙을 깨는 번호, 문패가 거의 없는 곳(LLM이 네 방향을 비슷하게 답함), 지도 노이즈.

**한계 (우리와 다른 점)**: 카메라·OCR이 없다. 글자와 벽을 사람이 미리 격자에 넣었고, 주변을 완벽히 본다고 가정했다. LLM 이름·크기, α 값, 프롬프트는 안 밝혔다. 실제 로봇(Spot)은 시연 1번.

**우리에게 주는 것**
- **LLM은 행동을 고르지 않고 "규칙과 방향 가설"만 낸다. 행동은 확신 값과 탐색 규칙이 정한다.** 우리 측정(서버 4B·12B가 다음 행동 최대 5/17, 규칙 15/17)과 같은 결론.
- **확신 값은 시간에 따라 줄고(잊고), 새 근거로 다시 쌓는다.** 우리 "기억 층"에 그대로 쓸 수 있다: 방향 가설(앞/뒤)마다 확신 값을 두고, 문패를 볼 때마다 갱신, 오래되면 줄인다.
- **LLM은 문패를 새로 봤을 때만 부르면 된다.** 매 3초가 아니라 근거가 바뀔 때.
- 우리 쪽에 더 필요한 것: 실제 OCR 오독(309→209, 300)과 벽 구분이 없는 기록. 논문은 깨끗한 입력이라 이 부분은 우리가 따로 풀어야 한다.

## 2. WalkVLM-LR (arXiv 2508.16070, 2025.8)

"Less Redundancy: Boosting Practicality of Vision Language Model in Walking Assistants". https://arxiv.org/abs/2508.16070

**문제**
- 출력 중복: VLM이 사진 설명하듯 길게 말한다.
- 시간 중복: 언제 말할지 판단을 못 해서 너무 자주 말한다. 판단을 큰 VLM에 맡기면 느리고, 작은 모델을 따로 두면 사진을 다시 읽어야 한다.

**방법**
- **환경 인식 판별기 (EAD)**: VLM의 시각 인코더 특징을 같이 쓴다(사진을 다시 읽지 않음). 지금 프레임 + 이전 3프레임 → 위험도 A/B/C. **위험이 높을 때만 언어 모델을 돌려 안내 문장을 만든다.** 아니면 말하지 않고 언어 모델도 안 돈다. 학습 데이터는 걷기 영상 20개에 사람이 A/B/C를 단 것.
- **짧게 말하도록 강화학습(GRPO)**: 보상 4개 = 길이(이상적 길이에서 벗어나면 감점), 자연스러움, 정확도, 핵심어 밀도.
- 기반 모델: Qwen2-VL-2B. 4비트로 약 2.9GB. 데이터셋 WAD(약 12k 영상, 10곳).

**결과**: "말할 때 판단" 점수(TRF, 위험도 F1) 0.670. 원래 WalkVLM 0.505, GPT-4o 0.430, Qwen2-VL 0.449. 출력 핵심어 밀도 0.576(비교 최고 0.459).

**한계**: 사용자 평가 7명·영상 3개, 판별기 학습 영상 20개. 임계값 숫자는 안 밝힘. 복잡한 장면에서는 여전히 길게 말함.

**우리에게 주는 것**
- **"말할지 말지"를 먼저 싼 판단으로 정하고, 말할 때만 무거운 모델을 쓴다.** 우리 "3초마다 안내"에 그대로 적용: 3초마다 말할 내용이 바뀌었는지(새 문패, 방향 확신 변화, 장소 변화)를 규칙으로 보고, 바뀌었을 때만 문장을 만든다. 안 바뀌면 짧은 신호음이나 침묵.
- **안내 문장은 짧게, 핵심어 위주로.** 우리는 학습 대신 문장 틀을 짧게 고치면 된다 ("315호 지남. 계속 직진.").
- 판단 근거는 지금 1프레임이 아니라 최근 몇 프레임(논문은 3). 우리 "기억"과 같은 방향.

## 3. 우리 구조에 합치면

| 단계 | 하는 것 | 근거 |
|---|---|---|
| 관측 (매 초) | YOLOE·OCR·Places365 | 지금 그대로 |
| 기억 (매 초) | 본 문패와 시각, 장소 흐름, **방향 가설별 확신 값**(시간 따라 줄고 근거로 쌓임) | Follow the Signs 확신 격자 |
| 가설 (근거가 바뀔 때만) | 텍스트 모델 / VLM이 "번호 규칙, 목적지 방향" 가설을 냄. 행동은 안 고름 | Follow the Signs: LLM 단독 0.16, 하이브리드 0.745 |
| 행동 (매 초) | 규칙이 확신 값과 사실로 행동 결정 (확신 없으면 탐색: 둘러보기·직진) | 프론티어 탐색으로 되돌아가기 |
| 말하기 (3초마다 검사) | 바뀐 게 있을 때만 짧은 문장, 없으면 신호음 | WalkVLM-LR 판별기 + 짧은 출력 |
