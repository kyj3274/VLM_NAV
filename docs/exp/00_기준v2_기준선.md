## 주의 (기준의 한계)
- 호실 후보와 `near` 판정이 **1단계 OCR 결과(pipeline_stage1.jsonl)에서만** 만들어졌다. OCR이 못 찾은 문패는 v1 조사에 있어도 near=false, v1에 없으면 정답에도 없다. → OCR 기반 방식(1·2단계)에 유리하게 치우침. 1·2단계의 가까운 호실 100%는 이 영향이 크다.
- dev 가까운 호실은 6개뿐이라 1개 차이가 17%p. 호실 F1·맞음/틀림 개수를 함께 볼 것.
- pipeline 결과에는 `vlm_called` 필드가 없다. `exp_00_baseline_stage{1,2}.jsonl`에 추가해 채점: 1단계는 VLM을 실제로 안 부르므로 false, 2단계는 `vlm_reasons`가 비어있지 않으면 true(vlm_seconds>0과 134장 모두 일치). 2단계 시간 = 1단계 시간 + VLM 시간.
- qwen 단독 결과에 실패 기록 있음(qwen3-vl 1장, qwen2.5vl 2장) → 빈 결과로 채점.
- score_v2.py의 `missing`은 ids를 먼저 거른 뒤 세서 항상 0 (결과 없는 사진은 조용히 빠짐). 4개 결과 모두 176장이라 이번엔 영향 없음.
