- 순서는 **1 → (엘리베이터) → 2a**, **1 → (엘리베이터) → 2b**의 두 갈래다. 2a와 2b는 서로 이어지지 않는다.
- 프레임 추출: `ffmpeg -i <영상> -vf fps=1 -q:v 2 -start_number 0 f%03d.jpg`
  - 1초에 1장, `f000`이 0초 장면이다.
  - 영상 회전 정보를 반영해 720×1280 세로로 저장했다.
- 원본 영상은 1280×720, 24fps이다. 그래서 **사진 데이터(3000~5700px)보다 해상도가 훨씬 낮고**, 문패 글자가 작다.
- 층과 호실 번호는 1단계 OCR 결과와 눈으로 본 것으로 적은 것이다. 사람 정답은 아니다.
